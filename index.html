Kazuji Media

Agregador de add-ons HTTP para Nuvio.

Para Nuvio Mobile Full com runtime assíncrono, adicione o manifesto completo em Plugins. Ele instala fornecedores por qualidade com fontes embutidas. Nas configurações de cada fornecedor, preencha TorBox · API key para devolver links HTTP de arquivos em cache. Não exige servidor Kazuji.

Você também pode instalar um fornecedor individual:

  • 4K · 2160p
  • Full HD · 1080p
  • HD · 720p
  • SD · 480p
  • Qualidade desconhecida (desativado por padrão)

Escolha o manifesto completo ou os individuais para evitar fornecedores duplicados. As configurações são individuais; fontes que exigem login próprio precisam do manifesto gerado por elas.

Para NuvioTV com runtime bloqueante, use o servidor HTTP. GitHub Pages não executa esse servidor. Manifesto legado com um único fornecedor.

Emblemas Fusion

Os resultados já incluem os metadados disponíveis para emblemas. Em Nuvio → Configurações → Streams → URLs de emblemas Fusion, importe o pacote Kazuji: https://joaovpimenta.github.io/kazuji-media/badges.json.

O pacote inclui resolução, fonte, codec, HDR, áudio, canais e edição. Ative Emblemas de tamanho e Logótipo do addon no Nuvio. O emblema de tamanho precisa do add-on HTTP; no plugin JS o tamanho aparece como texto quando conhecido.
