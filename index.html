Kazuji Media

Agregador de add-ons HTTP para Nuvio.

Para Nuvio Mobile Full com runtime assíncrono, adicione a URL do manifesto do plugin em Plugins e configure as fontes nas opções do Kazuji.

Para NuvioTV ou TorBox conectado ao Nuvio, use o servidor HTTP. GitHub Pages não executa esse servidor.

Emblemas Fusion

Os resultados já incluem os metadados disponíveis para emblemas. Em Nuvio → Configurações → Streams → URLs de emblemas Fusion, importe o pacote Kazuji: https://joaovpimenta.github.io/kazuji-media/badges.json.

O pacote inclui resolução, fonte, codec, HDR, áudio, canais e edição. Ative Emblemas de tamanho e Logótipo do addon no Nuvio. O emblema de tamanho precisa do add-on HTTP; no plugin JS o tamanho aparece como texto quando conhecido.
